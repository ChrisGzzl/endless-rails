# Endless Rails 开发期文件存档

按 2026-09-23 的最新决定，开发测试期使用 **JSON 文件模拟用户存档**，不接数据库，不接邮箱/第三方账号。一个测试 ID 对应一份服务器文件。ID 只是选择器，任何知道同一个 ID 的测试者都能读写它。

## 运行

需要 Node.js 22 或更新版本；没有第三方依赖，也不需要 `npm install`。

```sh
node services/player-data/server.cjs
```

打开 <http://127.0.0.1:4173/endless-rails/>，在「设置」Tab 进入「测试存档」，输入 `player-001` 等 ID。新用户默认空档，可明确选择导入原本游客进度。完成远征回到准备页后会自动同步，也可点「立即同步」。

同一个 ID 可以在不同浏览器中测试服务器存档恢复。单个浏览器只允许一个标签页操作测试存档，避免同一份本地缓存被旧页面覆盖。关闭原标签页后刷新即可重新使用。

可选环境变量：`PORT`（默认 4173）、`HOST`（默认 127.0.0.1）、`SAVE_DATA_DIR`（自定义持久化目录）。例如：

```sh
SAVE_DATA_DIR=/path/to/rails-saves PORT=4173 node services/player-data/server.cjs
```

服务只默认监听本机。需要局域网测试时，显式配置监听地址并使用可信开发环境；浏览器的 Web Locks、随机 UUID 等能力要求安全上下文，手机通过普通局域网 HTTP 访问时不能保证存档入口可用。此阶段不作为公开玩家账号服务。

GitHub Pages 只运行静态游戏，测试存档开关默认关闭。本地文件服务会返回开启该开关的配置。未部署可写服务器前，不把 Pages 上的本地存档描述成服务器存档。

## 文件和接口

首次产生需要同步的进度后创建文件，例如：

- `data/pl/player-001.json`：当前版本。
- `data/pl/player-001.previous.json`：上一版本。
- 游戏原来的游客 localStorage 不受测试用户切换影响；各测试用户的本机待上传缓存也分开保存。

数据目录默认不进入 Git。保留整个 `SAVE_DATA_DIR` 即可跨服务重启恢复。备份可在停服时复制该目录。需要人工恢复时，停服后保留当前文件副本，再用 `.previous.json` 替换对应 `.json`。

| 请求 | 内容 |
| --- | --- |
| `GET /api/health` | 服务状态，明确标记开发文件模式 |
| `GET /api/saves/:testId` | 当前版本与完整快照；新 ID 返回 `null` |
| `PUT /api/saves/:testId` | `{expectedRevision, mutationId, payload}` |

存档快照为 `{schemaVersion:1, meta, record}`，包括长期成长、编组、区域、研究、蓝图和历史战绩；不保存进行中战斗的位置、敌人和弹幕。声音/显示设置继续留在设备上。

写入采用同用户请求串行、版本比较、临时文件写入后重命名。旧版本提交返回 HTTP 409；相同请求重试不会再次增加版本。快照最大 32 KiB。接口不接受任意文件路径，也不直接暴露数据目录。

前端只在主页、准备页及结算阶段同步，自动同步最密每分钟一次；网络失败有退避重试。若关闭页面前尚未上传，进度保留在该测试用户的本机缓存，下次进入后继续上传。两台设备冲突不相加资源，也不直接覆盖；选择保留哪一份后再同步，并在本机保留替换前副本。

这是客户端上传的测试备份，不是可信结算：正式广告奖励、付费权益、排行榜和账户认证需后续单独实现。

## 10 万玩家的后续边界

本次不建数据库，也不声称单进程文件服务经过 10 万玩家并发验证。接口和存档格式保留，未来只替换存储适配层和加入真实认证。

| 规划假设 | 推导 |
| --- | --- |
| 10 万注册玩家，快照平均 4 KiB | 当前快照约 391 MiB；保留上一版后约 781 MiB，未计文件系统/备份开销 |
| 每人达到 32 KiB 上限 | 当前及上一版合计约 6.1 GiB，未计开销 |
| 峰值 2,000 在线、每分钟一次写入 | 理论约 33 次写入/秒；这只是容量输入，尚未压测验证 |
| 存档按 ID 前两位分目录 | 避免所有文件堆入单目录；实际分布仍取决于 ID |

文件版只运行一个进程，不可启动多个实例共写同一数据目录。准备公开运营或多实例部署时再迁移到数据库，并按实测日活、在线峰值、存档大小和写频率选型；10 万注册量不等于 10 万同时在线。

## 验证

```sh
node --test services/player-data/test/*.test.cjs
for f in endless-rails/*.test.js; do node "$f" || exit 1; done
```

服务测试使用真实临时文件及 HTTP 请求，覆盖不同用户、重启、原子替换、旧版本备份、同时写入冲突、重复请求、路径/体积校验、离线重试、同步中新增进度、明确导入、用户切换及战斗中禁止切换。UI 接入另有模拟 DOM 测试；未在真实手机上验证服务器存档。
