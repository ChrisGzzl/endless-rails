# Bottom navigation artwork · v2

These are the untouched transparent PNG outputs from the built-in ImageGen tool. The five `../nav-*-v2.webp` files are 192 px delivery copies. Keep the PNGs when recompressing or revising the UI.

The two September 26 UI reference screenshots were used only for style. Each prompt requested one isolated icon on transparency, bold simplified hard-edge game art, ivory and deep petrol teal with restrained amber, no text, no badge, no shadow, readable in the mobile dock:

| Source | Subject |
| --- | --- |
| `shop.png` | Frontier supply depot storefront, front view |
| `train.png` | Side-view modular rail carriage, without a locomotive nose |
| `depart.png` | Symmetric perspective railway track, without a train |
| `research.png` | Science flask with one cyan liquid accent |
| `settings.png` | Six-tooth mechanical cog |

Generated with the built-in ImageGen path, transparent background, then trimmed and downsampled with alpha preserved. The train delivery icon was fitted to a taller footprint for legibility at navigation size. Other game art remains in its original files.
